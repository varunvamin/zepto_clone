Zepto Clone (minimal)

This folder contains a tiny, minimal Zepto-like helper library for learning and experimentation.

Files:
- src/zepto.js — minimal DOM helper providing `$`, `.on()`, `.off()`, `.addClass()`, `.removeClass()`, `.css()`, `.attr()`, `.html()`, `.text()`, `.append()`, and `zepto.ajax()`.
- demo/index.html — simple demo page. Open it in your browser to try the API.

Quick start:
1. Open `frontend/zepto_clone/demo/index.html` in your browser.
2. Edit `src/zepto.js` to extend the API.
