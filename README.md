A responsive, high-performance web clone of the popular Zepto quick-commerce application. This project demonstrates modern frontend development practices, state management, and UI/UX design replication.

## ✨ Features
- **Product Catalog:** Browse through various categories of groceries and essentials.
- **Shopping Cart:** Add, remove, and update quantities of items dynamically.
- **Responsive Layout:** Beautiful UI that scales perfectly across mobile, tablet, and desktop devices.
- **Fast Load Times:** Optimized assets and efficient rendering for a smooth user experience.

## 🛠️ Local Development Setup

To run this clone locally on your machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/varunvamin/zepto_clone.git
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the development server**
   ```bash
   npm run dev
   # or npm start
   ```
4. **Open in Browser**
   Navigate to `http://localhost:3000` to view the application.
